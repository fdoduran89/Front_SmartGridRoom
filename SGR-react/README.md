Ejecutar el Frontend

Abrir una segunda terminal en Visual Studio Code.

Ingresar a la carpeta del frontend:

cd "D:\ETITC\Sistemas Operativos II\Front_SmartGridRoom\SGR-react"

Ejecutar el frontend:

pnpm dev

Vite mostrará una dirección similar a:

http://localhost:5173/

Abrir esta dirección en el navegador.

Mantener esta terminal abierta mientras se utiliza el sistema.
